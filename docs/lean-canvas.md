# بوم ناب | Lean Canvas

| Block | فارسی | English |
|---|---|---|
| Problem | سردرگمی در انتخاب فعالیت؛ دشواری یافتن ارائه‌دهنده معتبر؛ رهاکردن فعالیت پس از شروع | Uncertainty about suitable activities; provider discovery friction; low follow-through |
| Customer segments | زنان بزرگسال کرج، ابتدا فرضیه زنان شاغل ۲۵–۴۰ سال؛ ارائه‌دهندگان محلی | Adult women in Karaj, initially hypothesized working women aged 25–40; local providers |
| Unique value proposition | کشف کن چه فعالیتی برایت مناسب است و تجربه‌اش کن | Discover an activity that fits you, then try it |
| Solution | پرسشگری کوتاه، سه پیشنهاد توضیح‌پذیر، فهرست خدمات، درخواست رزرو، بازخورد | Short questionnaire, three explainable matches, service listings, booking requests, feedback |
| Channels | معرفی محلی، اینستاگرام، همکاری مراکز، کارگاه آزمایشی | Local referrals, Instagram, provider partnerships, trial events |
| Revenue streams | فرضیه کمیسیون ۱۰–۱۵٪ رزرو موفق؛ اشتراک B2B در آینده | Hypothesized 10–15% completed-booking commission; future B2B subscriptions |
| Cost structure | طراحی و توسعه، جذب عرضه، پشتیبانی، اعتبارسنجی، بازاریابی و حفاظت داده | Product development, provider onboarding, support, verification, marketing, data protection |
| Key metrics | تکمیل پرسشگری، انتخاب پیشنهاد، درخواست رزرو، حضور واقعی، رضایت و تکرار | Questionnaire completion, selection, booking requests, attendance, satisfaction, repeat use |
| Unfair advantage (hypothesis) | داده بازخورد واقعی از تطبیق علایق با تجربه؛ هنوز اثبات نشده | Learning from real preference-to-experience feedback; not yet proven |

## Existing alternatives | جایگزین‌های موجود
جست‌وجوی اینستاگرام، توصیه دوستان، تماس مستقیم با مراکز، فهرست کلاس‌ها.
Instagram search, word of mouth, direct provider booking, class directories.

## Validation status | وضعیت
All commercial assumptions remain unvalidated in Karaj. No revenue, demand, conversion or clinical benefit is claimed.
تمام فرضیه‌های تجاری در کرج نیازمند آزمون‌اند.
