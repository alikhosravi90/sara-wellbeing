# UX/UI Specification | مشخصات تجربه و رابط

## Design direction | جهت طراحی
Warm, trustworthy, calm, accessible; Persian RTL-first; optional English LTR. Soft lavender, sage green, warm neutrals. High contrast and readable typography. The previously discussed collage is **conceptual inspiration**, not implemented screens or validated usability.

## Primary user journey | سفر اصلی
Welcome → goals → mood/energy (optional, non-diagnostic) → preferences and constraints → explainable recommendations → activity details → booking request → provider confirmation → attendance → feedback → next discovery.

## Screens | صفحات
1. Welcome and consent / خوشامد و رضایت
2. Goals / اهداف
3. Energy and preferences / انرژی و ترجیحات
4. Activity interests / علایق
5. Recommendations and explanation / پیشنهادها و دلیل
6. Search and filters / جست‌وجو و فیلتر
7. Provider and activity details / جزئیات خدمت
8. Booking request and confirmation / درخواست رزرو
9. My experiences and feedback / تجربه‌ها و بازخورد
10. Provider/admin dashboard / پنل ارائه‌دهنده و مدیریت

## UX requirements | الزامات
- Let users skip sensitive questions / امکان رد پرسش حساس
- Never imply medical diagnosis / بدون تشخیص پزشکی
- Show price, location, cancellation policy and provider verification clearly / شفافیت اطلاعات
- Explain why an activity was suggested; let users reject it / توضیح‌پذیری و حق انتخاب
- No invented ratings or success metrics / عدم جعل امتیاز یا نتیجه
- Accessible controls and localization / دسترس‌پذیری و بومی‌سازی
