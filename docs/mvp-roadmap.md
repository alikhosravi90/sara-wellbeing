# MVP و نقشه راه | MVP Roadmap

## MVP scope | دامنه
1. Persian RTL mobile-first web app / وب‌اپ فارسی راست‌به‌چپ
2. 5–8 preference questions / ۵ تا ۸ پرسش ترجیحات
3. Rule-based, explainable top-three recommendations / سه پیشنهاد قاعده‌محور با دلیل
4. Provider catalog: category, neighborhood, price, schedule, suitability and verification status / کاتالوگ خدمات
5. Manual booking request and confirmation / درخواست و تأیید دستی رزرو
6. Post-activity feedback / بازخورد پس از تجربه
7. Admin moderation and provider verification / مدیریت و بررسی ارائه‌دهندگان

## Excluded from MVP | خارج از محدوده
Clinical diagnosis, therapy matching, automated payments, complex AI scoring, native mobile apps, social network, medical device integration.

## Pilot hypotheses | فرضیه‌های پایلوت
- One Karaj launch zone, initially Jahanshahr/Azimieh / یک محدوده اولیه در کرج
- Three categories: gentle movement, creative arts, social/nature activities / سه دسته فعالیت
- 10–15 verified providers, 100 pilot users / اهداف آزمایشی
- Target funnel: ≥60% questionnaire completion; ≥40% of completers select a suggestion; ≥20% request a booking; ≥10% attend; ≥70% of attendees report satisfactory fit. These are **proposed thresholds, not forecasts**.

## Eight-week sequence | برنامه هشت هفته
Weeks 1–2: 20–30 user interviews and 10 provider interviews; consent-based research.
Week 3: prototype, questionnaire and matching rules.
Weeks 4–5: minimal web app and manual operations dashboard.
Week 6: onboard and verify providers.
Weeks 7–8: pilot, analyze conversion, satisfaction, safety incidents and unit economics.

## Decision gates | گیت تصمیم
Discovery GO: documented user pain and willingness to try.
Pilot GO: verified supply, privacy notice, consent, safe referral and incident procedure.
Scale GO: actual attendance, acceptable unit economics, user satisfaction and no unresolved serious safety issues.
